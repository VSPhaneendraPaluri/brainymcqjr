### Name:
Project:  BrainyMCQ Junior
Website (preferred):  https://www.brainymcqjunior.com

### Goal
The objective is to create, host and maintain a highly competitive and randomly generated Maths-Sciences questionaire for students from Class 3 to Class 5 students.

### Requirements
- Kids must be able to create their login ID and password
- Save these passwords in the database so that the exams data isolation is maintained across students
- The quiz should have 25 questions from Mathematics and 25 questions from Sciences
- The questions should be MCQ (Multiple Choice Questions)
- There should be a timer set for the MCQ based quiz
- Both Maths and Sciences questions should appear subject-wise
- I should be able to store and maintain the history of scores scored by each student without losing it

### Platform Critera
- Thinking like the role of an Architect in Full-Stack Development, I want to use only open-source full-stack sources and libraries to build this data-base back, feature-rich, adaptive, flexible, scalable and responsive website
- I should be able to host it either locally or some free servers available in India
- The platform should be user friendly too to access and play the Quiz.
- List out the software in a requirements.txt file so that it could be used to re-create, deployable software anywhere else as well.
- Provide proper guidance to get started with for a new user on how to login, etc.
- Provide Submit button always for the candidate/student to submit his responses for the test and end the test.
- Show the overview of the current quiz summary upon completion of the test
- Add the results to the database of the student, maintain the history and track the progress
- The website should be HTTPS compliant for secure data transmission and user privacy protection

### Test
- Deploy the website locally to test the features.
