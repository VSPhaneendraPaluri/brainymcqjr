# Quick Render.com Deployment Reference

## TL;DR - 5 Minute Setup

### 1. Prerequisites
- ✅ GitHub account (push code there first)
- ✅ Render.com account (sign up at https://render.com)
- ✅ GitHub repo synced

### 2. Deployment Options

#### **Option A: Easiest - Auto Deploy with render.yaml** (Recommended)
```
1. Go to https://dashboard.render.com/blueprints
2. Click "New Blueprint Instance"
3. Select your GitHub repository
4. Render auto-creates: Web Service + PostgreSQL Database
5. Done! ✅
```

#### **Option B: Manual Deployment**
```
1. Create PostgreSQL database in Render
2. Create Web Service 
3. Point to GitHub repo
4. Set environment variables
5. Deploy ✅
```

### 3. Environment Variables Needed
```
FLASK_ENV=production
SECRET_KEY=(auto-generated by Render)
DATABASE_URL=(auto-set when using PostgreSQL)
PYTHON_VERSION=3.11
```

### 4. Access Your App
```
Your app will be live at:
https://brainymcq-junior.onrender.com
(or your custom domain)
```

## Files Added for Render Deployment

| File | Purpose |
|------|---------|
| `render.yaml` | **Infrastructure as Code** - Defines web service + database |

| `wsgi.py` | **Entry point** - For gunicorn (production server) |
| `requirements.txt` | Updated with `gunicorn` |
| `.gitignore` | Prevents sensitive files from committing |
| `RENDER_DEPLOYMENT.md` | **Full guide** with troubleshooting |

## Deployment Checklist

- [ ] Code pushed to GitHub (main branch)
- [ ] `render.yaml` file in repository root
- [ ] `requirements.txt` updated with gunicorn
- [ ] `FLASK_ENV=production` environment variable set
- [ ] `SECRET_KEY` environment variable set (Render can generate)
- [ ] `DATABASE_URL` pointing to PostgreSQL
- [ ] Web Service deployed and running
- [ ] Database tables created (happens automatically)
- [ ] Test login at deployed URL
- [ ] Test quiz functionality

---

## Troubleshooting Quick Links

| Issue | Solution |
|-------|----------|
| **502 Bad Gateway** | Check logs in Render → Logs tab |
| **Database error** | Verify DATABASE_URL environment variable |
| **Static files broken** | Ensure CSS/JS in `static/` folder committed |
| **App won't start** | Check requirements.txt has all dependencies |
| **Users can't login** | Database not initialized - check logs |

## Important Limits (Free Tier)

⚠️ **Know Before Deploying:**
- Service spins down after 15 min of inactivity (first request slow)
- 100MB PostgreSQL storage
- Limited to 2 concurrent processes
- `brainymcqjunior.onrender.com` domain (or custom)

✅ **Included Free:**
- HTTPS/SSL certificate (auto-renewed)
- Database backups
- GitHub auto-deploy
